# Claude CodeとCrazyrouterでExcelデータの整理・分析・レポート作成を行う

Excelのデータ処理では、重複行、空白セル、日付形式の混在、金額列の文字列化、不要な空行などがよく発生します。Claude Codeを使うと、これらを手作業で直すのではなく、確認可能なスクリプトと処理ログに落とし込めます。

全体ガイドはこちらです: [claude-code-guide](https://github.com/xujfcn/claude-code-guide?utm_source=zenn&utm_medium=article&utm_campaign=claude_code_guide_daily)

## エンドポイントを間違えない

Crazyrouterを使う場合、用途によってBase URLが異なります。

- Claude Code / Anthropicネイティブクライアント: `https://cn.crazyrouter.com`
- OpenAI互換SDK、HTTPリクエスト、Webアプリ: `https://cn.crazyrouter.com/v1`

OpenAI互換SDKに `/v1` 付きのURLを渡すべき場面と、Claude CodeにルートURLを渡す場面を混同すると、`/v1/v1/...` のようなパスになりやすいので注意します。

```bash
export ANTHROPIC_BASE_URL="https://cn.crazyrouter.com"
export ANTHROPIC_API_KEY="your_crazyrouter_token"
```

## Excel処理は「一発依頼」ではなくパイプライン化する

「このExcelをきれいにして」だけでは、処理内容が曖昧です。Claude Codeには、まず構造確認と処理計画を出させるのがおすすめです。

例:

> ワークブックを調査し、シート名、列名、行数、データ品質の問題を一覧化してください。変更前にクリーニング計画を提案してください。

その後で、以下のような手順に分けます。

1. 元ファイルを上書きしない
2. シートと列を確認する
3. 重複削除のキーを決める
4. 空白セルの扱いを列ごとに決める
5. 日付を `YYYY-MM-DD` に統一する
6. 金額列を数値としてパースする
7. 無効行を別シートに出す
8. 集計とレポートを生成する

## よくあるクリーニング処理

重複削除では、全列一致ではなく `order_id` や請求番号などの業務キーを指定します。たとえば「同じ `order_id` がある場合は `updated_at` が新しい行を残し、削除行は `duplicates_removed` シートに保存する」と依頼すると、監査しやすくなります。

空白セルは一律に「なし」で埋めない方が安全です。テキスト列、数値列、日付列では意味が違います。売上金額の空白を0にするか、欠損として扱うかは分析結果に影響します。

日付列も注意が必要です。Excelシリアル値、`2024/1/5`、`2024年1月5日` などが混在する場合、Claude Codeには変換ルールと無効値の出力を明示します。

## 分析とレポート

クリーニング後は、売上合計、平均、中央値、商品別・地域別集計、月次推移、顧客ランクなどを作れます。ただし、Claude Codeに「洞察を出して」と丸投げするより、目的を指定した方が実用的です。

例:

> 商品別、地域別、営業担当別に売上を集計してください。月次推移を折れ線グラフにし、使用した計算方法と前提条件をMarkdownレポートにまとめてください。

異常値検出や相関分析を行う場合は、必ず手法を説明させます。相関は因果ではありませんし、データ量が少ない場合は強い結論を避けるべきです。

## 実務でのチェックリスト

- 元ファイルを変更していないか
- 処理前後の行数が記録されているか
- 削除した重複行を確認できるか
- 無効な日付や金額が別管理されているか
- 金額列が文字列ではなく数値か
- グラフがクリーニング済みデータを参照しているか
- レポート内の提案がデータに基づいているか
- 来月も同じ処理を再実行できるか

Claude Codeは、Excel作業を自動化するだけでなく、処理内容をコードとログとして残せる点が便利です。Crazyrouterで接続先を統一しつつ、データ処理は必ず検証可能な形にしておくと、チーム運用に乗せやすくなります。
